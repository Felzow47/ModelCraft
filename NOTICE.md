### Open CASCADE (LGPL-2.1)

The Windows executables in `dist/` are **statically** linked with unmodified OCCT 7.8.1.
As the LGPL requires, you can relink ModelCraft with another OCCT version: all of ModelCraft's
source code is provided here, and the build procedure ("Building from source" in the README,
`OCCT_INC` / `OCCT_LIB` variables) rebuilds the executable with your own OCCT build. OCCT source:
https://github.com/Open-Cascade-SAS/OCCT/releases/tag/V7_8_1

### web-ifc and CDT (MPL-2.0)

The MPL-2.0 files (web-ifc, CDT) are used **without modification**; their source is available
at https://github.com/ThatOpen/engine_web-ifc (commit
`6b33ddf26c74d4881febaabf7a5bcb5259eccd96`) and https://github.com/artem-ogre/CDT. The only
special build flag is `-Dmapbox=wi_mapbox` (renames earcut's namespace to avoid a clash with the
copy of earcut bundled in assimp). The rest of ModelCraft is not subject to the MPL (file-level
copyleft).

### Formats not supported for license reasons

- **DWG**: the only complete free library (LibreDWG) is **GPL-3**; bundling it would put the
  whole executable under the GPL. Not included.
- **SketchUp `.skp`**: only Trimble's proprietary SDK reads it. Not included.
- **Rhino `.3dm`**: openNURBS has a permissive license, but it provides NURBS without a
  guaranteed render mesh; not integrated in this version.

The other Rust dependencies (egui, eframe, wgpu, glam, zip, roxmltree, image, rfd, winreg, cfb, memmap2…)
are under MIT / Apache-2.0 / zlib licenses; the full list is in `Cargo.lock`.

### Installer

`dist/ModelCraft-Setup-*.exe` is produced with **Inno Setup** (Jordan Russell / Martijn Laan,
Inno Setup license, free including for commercial use). The `installer/modelcraft.iss` script is
generated by `installer/gen_iss.py` (ModelCraft code). The open-source projects
*solidcraft* and *BIMCraft* were studied only as sources of ideas (see
`docs/REFERENCES.md`): none of their code is reused.

The screenshots in `assets/captures/` show only public sample files, which are not stored in this
